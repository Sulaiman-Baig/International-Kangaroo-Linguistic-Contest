# Kangaroo Linguistic Explorer (IKLC Ecolier, Class 3-4)

A single-file, offline study guide and practice app for the International Kangaroo Linguistic Contest, Ecolier level.

- 13 skill sections built from the official IKLC course outline and the 2022-2025 Ecolier papers
- Drawings, tables and a mini quiz in every section; a revision checklist saved in the browser
- 10 full-length practice papers: 3 parts, 24 questions, options A-E, 3/4/5 points, 120-minute timer and marking
- Stories, an invitation, a note with a timetable, picture and vocabulary questions, everyday English and grammar fill-ins

## Run

Open `index.html` in any browser. No internet or install needed.
